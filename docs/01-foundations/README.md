## Key Ideas

- LLMs are **next-token predictors** trained on massive text corpora.
- They do not "know" facts — they learn statistical patterns.
- Embeddings are the bridge between text and math (vector spaces).
- Tokenization affects cost, context length, and multilingual capability.
- Hallucination is an inherent property; mitigation requires grounding (RAG, tool use, citations).
