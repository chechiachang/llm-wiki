# Workshop: RAG打造企業AI知識庫：把一甲子功力傳給新人

**Event**: DevOpsDay Taiwan 2025  
**Date**: 2025-06-05  
**Type**: Workshop (hands-on)  
**Source**: <https://chechia.net/zh-hant/posts/2025-06-06-devops-rag-internal-ai/>

## Description

學員將學會如何利用 RAG 技術，結合 OpenAI、LangChain、Qdrant 向量數據庫，構建企業內部文檔的智能知識庫，並能設計與實作一個基於自然語言處理（NLP）的查詢系統，來提升開發團隊的效率與知識管理能力。

## Outline

- 什麼是 RAG（Retrieval-Augmented Generation）
- Python 與 OpenAI API
- LangChain 框架介紹
- Qdrant 向量數據庫
- 構建 RAG 系統：數據預處理、Embedding、向量檢索
- 系統評估（RAGAS）

## Prerequisites

- Docker
- Python + Jupyter Notebook
- SSH (for remote VM option)
