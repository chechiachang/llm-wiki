# RAG 打造企業知識庫入門，從 embeddings 到 evaluation

**Event**: Hello World Dev Conf 2025  
**Date**: 2025-10-15  
**Type**: Workshop (hands-on, 90 min)  
**Source**: <https://chechia.net/zh-hant/posts/2025-10-15-hwdc-rag/>

## Description

學員將學會如何利用 RAG 技術，結合 OpenAI、LangChain、Qdrant 向量數據庫，構建企業內部文檔的智能知識庫。

## Outline

- 為什麼需要 RAG
- Embedding 與向量數據庫
- Embedding Search
- DIY 實作
- Evaluation（RAGAS）
- k8s RAG QA 實際應用

## Outcomes

After the workshop, participants can:
- Understand and implement RAG
- Build retrieval-based QA with Python and OpenAI
- Use Qdrant for efficient retrieval
